Database Design (Cafeteria Management System)

1. Database Tables

Users

  • id (PK)
  • username
  • email
  • phone_number
  • password_hash
  • role
  • employee_id
  • dietary_restrictions
  • created_date
  • last_login
  • is_active

MenuItems

  • id (PK)
  • name
  • category
  • description
  • price
  • calories
  • allergens
  • chef_id (FK)
  • creation_date
  • status
  • image_url

Orders

  • id (PK)
  • customer_id (FK)
  • order_date
  • total_amount
  • status
  • payment_method
  • delivery_preference
  • special_instructions
  • estimated_ready_time

OrderItems

  • id (PK)
  • order_id (FK)
  • menu_item_id (FK)
  • quantity
  • unit_price
  • special_requests

Inventory

  • id (PK)
  • item_name
  • quantity
  • unit
  • reorder_level
  • expiration_date
  • supplier_id (FK)

2. Relationships

  • User → Order : One-to-Many (customer)
  • User → MenuItem : One-to-Many (chef)
  • Order → OrderItem : One-to-Many
  • MenuItem → OrderItem : One-to-Many
  • Supplier → Inventory : One-to-Many
  • User → AuditLog : One-to-Many
