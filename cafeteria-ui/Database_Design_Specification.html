Database Design

1. Database Tables

Users

  • id (PK)
  • name
  • phone_number
  • email
  • password_hash
  • role
  • created_date
  • last_login
  • is_active

Projects

  • id (PK)
  • name
  • description
  • manager_id (FK)
  • start_date
  • end_date
  • methodology
  • status
  • health

Tasks

  • id (PK)
  • project_id (FK)
  • title
  • assignee_id (FK)
  • priority
  • status
  • story_points
  • due_date
  • sprint_id (FK)

Sprints

  • id (PK)
  • project_id (FK)
  • name
  • start_date
  • end_date
  • story_points_committed
  • story_points_completed
  • status

TimeEntries

  • id (PK)
  • task_id (FK)
  • user_id (FK)
  • hours
  • date
  • description
  • status

2. Relationships

  • User → Project : One-to-Many (manager)
  • Project → Task : One-to-Many
  • User → Task : One-to-Many (assignee)
  • Project → Sprint : One-to-Many
  • Sprint → Task : One-to-Many
  • Task → TimeEntry : One-to-Many
  • User → TimeEntry : One-to-Many
